# Task_shipsailing
Completed task for recruitment process. Created in Unity Engine v. 6000.5.11f1.  
Game executable is in 'Game' folder.  

SHIP STEERING  
W, S - furl/unfurl the sail.  
A, D - rotate the ship.  
Q, E - rotate the mast.  

ADDITIONAL INFO  
The wind has static speed and direction. The project contains additional scripts for generating waves (render and behaviour) but they are not attached to the waterplane.
